# Collapse Chain Theorems

What a run of consecutive COLLAPSING levels does to the tower.

Measured maximal COLLAPSING runs (`K <= 3000`):

```
    (2, 2)   (4, 7)   (9, 28)   (30, 399)   (401, 3000)
```

The chains are exactly the gaps between the non-collapsing levels
`K = 3, 8, 29, 400`. The last chain has length **2600** and is still running at
the top of the computed range.

---

## 1. The cycle-word transducer — **THEOREM CH1**

Fix a maximal chain `A <= K <= B` on which the period is constant, `P(K) = P`,
and fix a reference time `T*` with `T* >= T(K)` for every `K` in the chain.
Define the **cycle word**

```
    C_K = ( w_{T*}(K), w_{T*+1}(K), ..., w_{T*+P-1}(K) )  in  {0,1}^P .
```

> For every `K` in the chain with `K-1, K-2` also in it, `C_K` is the **unique**
> `P`-periodic solution `u` of
> ```
>     u_{j+1} = C_{K-2}[j] XOR ( C_{K-1}[j] OR u_j ),      indices mod P.
> ```
> Hence there is a fixed map `Psi` with `C_K = Psi( C_{K-2}, C_{K-1} )`.

*Proof.* Existence: the actual orbit provides one. Uniqueness: the composition
around the cycle is the constant map `Phi` (Theorem R2), so the fixed-point
equation `u_0 = Phi(u_0)` has the single solution `u_0 = Phi`, and the rest of
the word is then determined by iteration. ∎

*Verification.* On the chain `[402, 3000]`: **2598 levels checked, 2598 with a
unique solution, and the measured cycle word is that solution in every case.**

## 2. Bounded memory — **COROLLARY CH2**

> The map
> ```
>     ( C_{K-2}, C_{K-1} )  |-->  ( C_{K-1}, C_K )
> ```
> is a deterministic map on `{0,1}^{2P}`. Along a collapse chain the entire
> tower of cycle words is generated by iterating **one fixed map on `2P` bits**.

At `P = 16` the memory is **32 bits**. The dependency cone in the prefix-index
direction has **width 2 and does not grow**: `C_B` is determined by
`(C_{A-1}, C_A)` for any lower level `A` of the chain, no matter how long the
chain is.

This answers the brief's three questions about chains:

* **finite dependency cone in the prefix direction** — yes, width exactly 2
  (**THEOREM**);
* **synchronisation of all initial fibre values** — yes, by Corollary R1a each
  collapse merges orbits differing in that fibre, so along a chain of length `L`
  all `2^L` initial fibre assignments collapse onto one (**THEOREM**);
* **bounded-memory transducer from lower to higher cycle words** — yes,
  `2P` bits (**THEOREM CH2**).

## 3. Pigeonhole — **THEOREM CH3**, and why it is empty here

> If a COLLAPSING chain of constant period `P` has length greater than `2^{2P}`,
> the sequence `(C_{K-1}, C_K)` must repeat, and the cycle words are then
> **periodic in `K`** with period at most `2^{2P}`.

*Proof.* Iterating a fixed map on a set of size `2^{2P}` (CH2). ∎

**Honest assessment: CH3 has no empirical content.** At `P = 16` it requires a
chain of `2^{32} ≈ 4.3 x 10^9` levels; the longest chain measured is **2600**.
Whether a chain that long exists is unknown — it would require no doubling
point for four billion levels, and the four observed doubling points are at
`3, 8, 29, 400`, i.e. increasingly far apart but on nothing like that scale.
CH3 is recorded as a theorem with a vacuous hypothesis at present.

## 4. What a chain does **not** do

* **It does not bound the transient.** CH1–CH3 describe the *cycle*; the
  diagonal lives in the transient (Phase 2C: `T(K) ≈ 1.34K > K`), and the
  transducer says nothing there.
* **It does not make the tower eventually periodic in `K`** at any observed
  scale (see CH3).
* **It gives no information flow towards the diagonal.** The dependency cone of
  width 2 runs in the prefix-index direction *within the cycle*; the diagonal
  crosses levels at unit speed in time, staying below the periodic frontier.
  `DIAGONAL_DEPENDENCY.md` quantifies exactly how much of the diagonal's
  ancestry is cycle-determined (about 19% of the backward time range is
  entirely transient).
